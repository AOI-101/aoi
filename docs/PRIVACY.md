# 公開前の確認

このリポジトリのファイル・ブランチ・PR・Issue・コミットの説明は公開前提です。
内部のDriveリンク、交接本文、個人の作業履歴、端末情報は載せません。

- 認証情報：パスワード、APIキー、アクセストークン、秘密鍵、認証用QRを含めない。
- 個人情報：スクリーンショット、ログ、実名メール、個人フォルダー名も確認する。
- .env.exampleを作る場合は架空の値だけを使う。
- コミット作者のメールも公開され得るため、GitHubのメール設定で確認したnoreplyアドレスを使う。
- Drive交接台の共有範囲を確認し、内部文書をリンクを知る全員へ公開しない。
- 秘密情報はリポジトリ外で保管する。除外ディレクトリも暗号化はされない。

.gitignoreは安全装置の一部です。既に追跡済みのファイルには効かず、
GitHub画面からのアップロードを阻止するものでもありません。
コミット前に差分そのものを確認します。

誤って秘密を公開した場合：該当キーを発行元で失効・再発行し、公開範囲と履歴を確認してください。
最新ファイルから削除するだけでは履歴から消えません。

参考：[Git公式 gitignore](https://git-scm.com/docs/gitignore)
