# aoi — PC・Mobile・Codex 作業の入口

公開可能なコードと説明のバージョン管理（版本管理）用リポジトリです。
PCの既存プロジェクトは、未同期の変更を含む作業原本として保護します。
GitHubの main は、比較・確認後に共有したコードの基準です。
Google Driveの既存交接台は、作業状況とモバイルで生まれた追加内容の引継ぎに使います。

## 最初に読む

1. [同期・初回導入ガイド](docs/SYNC.md)
2. [空欄の引継ぎテンプレート](templates/HANDOFF.md)
3. [公開前の確認](docs/PRIVACY.md)

## 役割

| 場所 | 入れるもの |
| --- | --- |
| PC | 実際の作業ファイル、実行・検証環境、未同期の変更 |
| GitHub | 公開できるコード、一般的な説明、確認済み変更の履歴 |
| Google Drive | 既存の交接台、内部メモ、モバイル追加内容、未統合の成果物 |
| Codex | アクセスできる資料の比較、変更案、検証。端末の常時接続は前提にしない |

公開ブランチ・PR（合并请求）も公開です。秘密情報を置く場所にはなりません。
GitHubへの保存だけでは、PCへのダウンロードやDriveとの同期は発生しません。

## 基本構成

- src/ — 公開可能なコード
- docs/ — 操作説明
- templates/ — 空欄テンプレート。記入した内部版はDriveへ
- AGENTS.md — Codex向けの作業ルール
- .gitignore — ローカルの未追跡ファイルをGitの対象から除外
- .gitattributes — テキストの改行を統一

初期状態にアプリ、依存パッケージ、自動同期、端末接続設定は含みません。
